# Homebrew tap for Timebirdss

```bash
brew install --cask Timebirdss/tap/app-updates
```

| Cask | What it is |
|---|---|
| `app-updates` | [App Updates](https://github.com/Timebirdss/swiftbar-app-updates) — Homebrew and Mac App Store updates in your SwiftBar menu bar |

## How this tap works

Casks live in `Casks/` and are versioned independently of the main repository.
When a new release is tagged, the cask here is bumped to that tag and its `sha256`.
